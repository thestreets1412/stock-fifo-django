- Paths are relative to the working directory set in the systemd unit (`WorkingDirectory=/home/appuser/stock-fifo-django`)

## Shared Patterns

### Middleware Insertion Pattern

**Source:** `config/settings.py:61-69` (existing MIDDLEWARE list)

**Pattern for adding middleware to Django:**
- Insert into the `MIDDLEWARE` list in `config/settings.py`
- Order matters: WhiteNoiseMiddleware must come after SecurityMiddleware (it short-circuits, so anything earlier in the list won't run for static requests)
- Middleware is specified as a dotted string path: `'whitenoise.middleware.WhiteNoiseMiddleware'`
- No instantiation or `()` in the string

**Apply to:** All future middleware additions should follow this pattern (order-sensitive insertion).

---

### Configuration Pattern via Python Modules

**Source:** `config/settings.py` and `config/wsgi.py` (existing Python configuration modules)

**Pattern:**
- Configuration files are Python modules, not JSON/YAML/INI
- Use `pathlib.Path` for filesystem paths (e.g., `BASE_DIR / 'staticfiles'`)
- Use environment variables via `decouple.config()` for secrets/deployment-specific values (see RESEARCH.md's Open Question 2 for the systemd `User=` value)
- Top-level variables are the configuration values (gunicorn loads them directly)

**Apply to:** `config/gunicorn_conf.py` follows this same pattern for WSGI-layer configuration.

---

### Django 6.0+ STORAGES Configuration Pattern

**Source:** `config/settings.py:136-143` (existing STATIC_ROOT, MEDIA paths)

**Pattern:** Django 6.0 uses a `STORAGES` dict with `"default"` and `"staticfiles"` keys. Each key has a `BACKEND` that determines how files are stored/served.

```python
STORAGES = {
    "default": {
        "BACKEND": "django.core.files.storage.FileSystemStorage",
    },
    "staticfiles": {
        "BACKEND": "whitenoise.storage.CompressedManifestStaticFilesStorage",
    },
}
```

**Rationale:** Separates media uploads (default, unchanged) from static asset serving (staticfiles, now whitenoise).

**Apply to:** If any future phase needs to modify static storage or media storage backends, use this `STORAGES` dict format (not the deprecated `STATICFILES_STORAGE` single-string setting).
